# Screenshot della documentazione

Specifiche Playwright che producono gli screenshot di `src/assets/screenshots/{light,dark}/`
sui dati dimostrativi (`arenile seed demo`), in tema chiaro e scuro. Si eseguono con
`make docs-screenshots` usando l'installazione di Playwright di `e2e/`. Le immagini si
rigenerano a ogni release: non modificarle a mano.

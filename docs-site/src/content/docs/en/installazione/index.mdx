Arenile is **a single program**: one binary that contains the manager panel, the public booking page, the APIs
and the database (SQLite, or PostgreSQL if you prefer). No Redis, message queues or paid services: a small
server is enough for a whole beach.

This section has two parts.

<Aside type="note" title="Where to get Arenile">
  **GitHub** hosts the source code and the instructions to build and run it: prebuilt binaries are not published
  there. The **Docker image** on GitHub Container Registry (`ghcr.io/coste360/arenile`) is public and free.
  **Ready-made packages** for Windows, macOS and Linux (desktop edition) are on
  [arenile.app/download](https://arenile.app/download/), no sign-up needed.
</Aside>

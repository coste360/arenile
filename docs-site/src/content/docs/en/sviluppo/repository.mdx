## Dependency rules

- `internal/domain/*` does not import `net/http`, `internal/http/*` or SQL drivers: it takes part in transactions with
  `bun.IDB`.
- `internal/http/*` contains no SQL or business logic: decode, call the service, encode.
- `internal/domain/pricing` does not import `store` or `clock`, nor use `time.Now`.
- `pkg/ext` imports nothing from `internal/`.
- Every operational query filters by `establishment_id`, taken from the authenticated context
  (`EstablishmentScope`), never from the request body.

## Generated code

<Aside type="danger" title="Never by hand">
  These files are regenerated with `make gen`; `make check` fails if they differ from what is committed.
</Aside>

| Generated | From |
|---|---|
| `internal/http/api/*.gen.go` | `api/openapi.yaml` (oapi-codegen) |
| `web/shared/api/generated/**` | `api/openapi.yaml` (openapi-typescript) |
| `web/shared/src/map/kit/generated/**`, `internal/domain/mapping/kitassets_gen.go` | `assets/beach-map-kit` (`web/scripts/gen-map-kit.mjs`) |

## Migrations

One pair of files per schema version, with the same number, in `internal/migrations/sqlite/` and
`internal/migrations/postgres/` (goose). A migration already on `main` is never modified: you add the next one.

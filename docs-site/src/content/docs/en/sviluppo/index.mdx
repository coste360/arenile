Arenile is released with available source code (BSL 1.1): you can read it, modify it, extend it and contribute. This
section is for people who write code: developers, integrators, driver authors.

```text
Go (single binary)  chi · oapi-codegen · Bun · SQLite (modernc, no CGO) | PostgreSQL (pgx) · goose · slog
Frontend            React · strict TypeScript · Vite · TanStack Router/Query · shadcn/ui · Tailwind · i18next
Contract            api/openapi.yaml (OpenAPI 3.1) → generated Go server and TypeScript client
Tests               Go table-driven and property-based (rapid) · SQLite+PostgreSQL integration · -race · Vitest · Playwright
```

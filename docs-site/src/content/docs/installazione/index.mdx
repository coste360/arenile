Arenile è **un solo programma**: un binario che contiene il pannello del gestore, la pagina di prenotazione
pubblica, le API e il database (SQLite, oppure PostgreSQL se preferisci). Non servono Redis, code di messaggi
o servizi a pagamento: un server piccolo basta per un lido intero.

Questa sezione è divisa in due parti.

<Aside type="note" title="Dove si scarica Arenile">
  Su **GitHub** trovi il codice sorgente e le istruzioni per compilarlo ed eseguirlo: i binari pronti non vengono
  pubblicati lì. L'**immagine Docker** su GitHub Container Registry (`ghcr.io/coste360/arenile`) è pubblica e
  gratuita. I **pacchetti pronti** per Windows, macOS e Linux (edizione desktop) si scaricano da
  [arenile.app/download](https://arenile.app/download/), senza registrazione.
</Aside>

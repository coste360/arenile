| Termine | Significato |
|---|---|
| **Abbonamento stagionale** | Prenotazione con formula stagione che riserva una postazione a un cliente per tutta la stagione. Vedi [Abbonamenti](/gestore/abbonamenti/). |
| **Acconto** | La parte del totale da pagare alla prenotazione, decisa dalla [policy](/gestore/policy/). |
| **Allocazione** | L'occupazione di una risorsa (postazione o unità di pool) per una data e una fascia. È ciò che impedisce le doppie vendite. |
| **Area di gestione** | La pagina "La tua prenotazione" che il cliente apre dal link magico. |
| **Assegnazione automatica** | Scelta automatica della postazione per le righe delle zone in modalità Zona, alla conferma. |
| **Blocco (hold)** | Occupazione temporanea di una risorsa mentre il cliente completa la prenotazione online; scade da solo. |
| **Blocco manuale** | Postazione resa non prenotabile dal personale, con un motivo. |
| **Canale** | Origine della prenotazione: **Cassa**, **Online**, **API**. |
| **Categoria di prezzo** | Chiave (es. `row1`) usata dalle regole di prezzo; si imposta sulla zona o, come eccezione, sulla postazione. |
| **Check-in** | Registrazione dell'arrivo del cliente: la prenotazione diventa **Presente**. |
| **Chiusura** | Giorno o mezza giornata di chiusura straordinaria. |
| **Chiusura Z** | Riepilogo stampabile della sessione di cassa chiusa. |
| **Componente** | Attrezzatura fisica consumata da un pack: ombrellone, lettino, sdraio, cabina. |
| **Condizioni** | Il testo che il cliente accetta prenotando online, pubblicato in versioni immutabili. |
| **Convenzione** | Sconto per un partner o un gruppo di clienti, dal pannello o con un codice. |
| **Copertura** | Verifica che ogni pack attivo abbia un prezzo in ogni giorno per ogni categoria. |
| **Corrispettivi** | Riepilogo degli incassi per aliquota IVA e metodo, per il commercialista. |
| **Credito** | Saldo a favore del cliente (da cancellazione, maltempo, rilascio rivenduto, manuale). |
| **Elemento** | Oggetto non prenotabile della mappa: passerella, doccia, bar, bandiera… |
| **Extra** | Aggiunta opzionale a un pack o alla prenotazione: lettino aggiuntivo, cabina, parcheggio. |
| **Fascia** | Unità di tempo minima: **Mattina** (AM) e **Pomeriggio** (PM). La giornata intera occupa entrambe. |
| **Formula** | Tipo di durata: mezza giornata, giornata, più giorni, settimana, quindicina, mese, stagione. |
| **Generatore di file** | Strumento dell'editor che crea N file di M postazioni numerate. |
| **Kit grafico** | Le illustrazioni Coste360 usate per disegnare postazioni ed elementi della mappa. |
| **Link magico** | Il link personale nell'email di conferma che apre l'area di gestione. |
| **Mappa** | Disegno di un'area dello stabilimento (spiaggia, piscina). |
| **Modalità di assegnazione** | Come si vende una zona: **Posto scelto**, **Zona**, **Quantità**. |
| **Pack** | Prodotto vendibile composto da componenti (es. 1 ombrellone + 2 lettini). |
| **Periodo tariffario** | Intervallo di date con un codice (bassa, media, alta, picco) usato dalle regole di prezzo. |
| **Policy** | Regole di prenotazione: anticipo, durata, pagamento, cancellazione, approvazione. |
| **Pool** | Inventario a quantità senza posizione: lettini liberi, cabine, posti auto. |
| **Postazione** | Elemento prenotabile con una posizione sulla mappa: ombrellone, gazebo, tenda, palma, lettino… |
| **Quota online** | Limite di quanto di una zona si vende online (e via API) per data e fascia. |
| **Regola di prezzo** | Una riga del listino: fase, destinatari, condizioni, azione, priorità. |
| **Riconciliazione** | Controllo periodico con Stripe dei pagamenti in sospeso, per recuperare i webhook persi. |
| **Rilascio** | Giorno in cui un abbonato libera la propria postazione, che torna in vendita. |
| **Riga di prenotazione** | Un pack prenotato con la sua postazione, zona o quantità. |
| **Sessione di cassa** | Periodo tra apertura e chiusura della cassa. |
| **Simulatore** | Strumento che calcola un prezzo mostrando ogni regola applicata. |
| **Stabilimento** | Un lido, con fuso orario, stagioni, mappe, catalogo, listini, policy e pagina pubblica. |
| **Stagione** | Periodo di apertura di un anno. |
| **Webhook** | Messaggio firmato che un servizio esterno (Stripe) invia ad Arenile, o che Arenile invia a un'integrazione. |
| **Zona** | Raggruppamento di postazioni o attrezzature vendute allo stesso modo (Prima fila, Gazebo, Piscina). |

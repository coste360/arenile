Arenile è distribuito con codice sorgente disponibile (BSL 1.1): puoi leggerlo, modificarlo, estenderlo e
contribuire. Questa sezione è per chi scrive codice: sviluppatori, integratori, autori di driver.

```text
Go (monobinario)   chi · oapi-codegen · Bun · SQLite (modernc, senza CGO) | PostgreSQL (pgx) · goose · slog
Frontend           React · TypeScript strict · Vite · TanStack Router/Query · shadcn/ui · Tailwind · i18next
Contratto          api/openapi.yaml (OpenAPI 3.1) → server Go e client TypeScript generati
Test               Go table-driven e di proprietà (rapid) · integrazione SQLite+PostgreSQL · -race · Vitest · Playwright
```

## Regole di dipendenza

- `internal/domain/*` non importa `net/http`, `internal/http/*` né driver SQL: partecipa alle transazioni con
  `bun.IDB`.
- `internal/http/*` non contiene SQL né logica di business: decodifica, chiama il servizio, codifica.
- `internal/domain/pricing` non importa `store`, `clock` né usa `time.Now`.
- `pkg/ext` non importa nulla di `internal/`.
- Ogni query operativa filtra per `establishment_id`, preso dal contesto autenticato (`EstablishmentScope`), mai
  dal corpo della richiesta.

## Codice generato

<Aside type="danger" title="Mai a mano">
  Questi file si rigenerano con `make gen`; `make check` fallisce se differiscono da quanto versionato.
</Aside>

| Generato | Da |
|---|---|
| `internal/http/api/*.gen.go` | `api/openapi.yaml` (oapi-codegen) |
| `web/shared/api/generated/**` | `api/openapi.yaml` (openapi-typescript) |
| `web/shared/src/map/kit/generated/**`, `internal/domain/mapping/kitassets_gen.go` | `assets/beach-map-kit` (`web/scripts/gen-map-kit.mjs`) |

## Migrazioni

Una coppia di file per ogni versione dello schema, con lo stesso numero, in `internal/migrations/sqlite/` e
`internal/migrations/postgres/` (goose). Una migrazione già su `main` non si modifica mai: si aggiunge la
successiva.

# Arenile UI kit (shadcn/ui)

shadcn/ui is **the** component system of the admin panel and of the public booking page.
Components live here, are generated by the shadcn CLI (Tailwind v4, Radix primitives,
lucide-react icons) and are imported by both apps from `@arenile/shared/ui`.

**No custom CSS.** Styling = shadcn variants + Tailwind utilities. No `.css` files, CSS
modules, CSS-in-JS or `style={{…}}` (except dynamic SVG geometry in the map). The only
stylesheet is the theme `web/shared/src/styles/globals.css`. `npm run lint`
(`web/scripts/css-guard.mjs`) enforces this.

## Imports

| What                                                         | Import                                                                                |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------- |
| shadcn components (barrel)                                   | `import { Button, Card, Dialog } from '@arenile/shared/ui'`                           |
| one component (preferred in **web/booking**, smaller bundle) | `import { Button } from '@arenile/shared/ui/button'`                                  |
| Arenile patterns                                             | `import { PageHeader, DataTable, MoneyInput } from '@arenile/shared/ui/patterns'`     |
| class merge                                                  | `import { cn } from '@arenile/shared/lib/utils'` (or from the ui barrel)              |
| money / dates helpers                                        | `@arenile/shared/lib/money`, `@arenile/shared/lib/dates`                              |
| icons                                                        | `import { PlusIcon } from 'lucide-react'` (decorative: `aria-hidden="true"`)          |
| toasts                                                       | `import { toast } from 'sonner'` (the `<Toaster/>` is mounted in `admin/src/App.tsx`) |

Available components: accordion, alert, alert-dialog, avatar, badge, breadcrumb, button,
button-group, calendar, card, chart (recharts), checkbox, collapsible, command, context-menu,
dialog, drawer, dropdown-menu, empty, field, form (react-hook-form), hover-card, input,
input-group, kbd, label, pagination, popover, progress, radio-group, resizable, scroll-area,
select, separator, sheet, sidebar, skeleton, slider, sonner, spinner, switch, table, tabs,
textarea, toggle, toggle-group, tooltip.

### Adding a component

```bash
cd web && npx shadcn@latest add <name> --cwd shared
npx prettier --write shared/src/ui/<name>.tsx
```

`web/shared/components.json` writes it to `shared/src/ui/<name>.tsx` with
`@arenile/shared/ui/*` imports; add `export * from './<name>';` to `ui/index.ts`.
If the CLI tries to install a dependency that conflicts (e.g. `@hookform/resolvers@latest`),
install the deps manually with the versions already in use and view the source with
`npx shadcn@latest add <name> --view src/ui/<name>.tsx --cwd shared`.
Hard-coded English strings in generated code must go through `t('ui.…')`.

### Local changes to generated components (keep them when re-adding)

- `button`: `type="button"` by default (never submits a form unless `type="submit"`).
- `dialog`: optional `closeLabel` prop; close/sheet/sidebar/breadcrumb/pagination/command/
  spinner strings are translated (`ui.*` keys).
- `form`: `FormMessage` translates the zod message (messages are i18n keys).
- `sonner`: uses our `useTheme` (no next-themes); `breadcrumb`: `BreadcrumbPage` has no fake
  `role="link"`; `hooks/use-mobile`: `useSyncExternalStore` version.

## Theme tokens

Use the semantic Tailwind classes, never raw palette colours (`slate-*`, hex):

| Token                         | Classes                                                                                                                    | Use                                                               |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------- |
| background / foreground       | `bg-background text-foreground`                                                                                            | page                                                              |
| card, popover                 | `bg-card text-card-foreground`                                                                                             | surfaces                                                          |
| primary (deep sea blue)       | `bg-primary text-primary-foreground`                                                                                       | main actions, selection                                           |
| primary-on-surface            | `text-primary-on-surface`                                                                                                  | links / brand text on surfaces (contrast-safe with custom themes) |
| highlight (warm sand)         | `bg-highlight text-highlight-foreground`                                                                                   | badges, "presto", highlights                                      |
| secondary, muted, accent      | `bg-muted text-muted-foreground`, `hover:bg-accent`                                                                        | secondary text, hover                                             |
| destructive, success, warning | `text-destructive`, `bg-success/15`, `bg-warning/20`                                                                       | states                                                            |
| border, input, ring           | `border`, `border-input`, `ring-ring`                                                                                      |                                                                   |
| chart-1…5                     | `var(--chart-1)` in `ChartConfig`                                                                                          | charts                                                            |
| sidebar-*                     | sidebar internals                                                                                                          |                                                                   |
| map surfaces                  | `fill-map-sand`, `fill-map-sea`, `fill-map-decoration`, `stroke-map-spot-stroke`                                           | map                                                               |
| spot statuses                 | `STATUS_CLASSES[status].fill / .labelFill / .bg` from `@arenile/shared/map` (`--status-free`, `--status-booked-online`, …) | map, legends, badges                                              |

Radius: `--radius: 0.75rem` (`rounded-lg` = radius, `rounded-md`/`rounded-sm` smaller).
Font: Inter Variable (`@fontsource-variable/inter`, `font-sans`). Dark mode: `.dark` on
`<html>` via `ThemeProvider` (light/dark/system, stored in `localStorage['arenile-theme']`).

Public booking page: `applyTheme()` (`@arenile/shared/theme`) writes `--primary`,
`--primary-foreground`, `--primary-on-surface`, `--highlight(-foreground)`, `--radius`,
`--app-font` from the establishment theme (spec 12.5, WCAG contrast computed in
`theme/contrast.ts`), so the same shadcn components follow the establishment brand.

The pre-shadcn `--ar-*` variables have been removed; the CSS guard rejects them.

## Patterns (`@arenile/shared/ui/patterns`)

```tsx
// Page skeleton
<section aria-labelledby="page-title" className="space-y-6">
  <PageHeader
    title={t('zones.title')}
    description={t('zones.description')}
    actions={
      <Button onClick={openNew}>
        <PlusIcon aria-hidden="true" />
        {t('common.actions.create')}
      </Button>
    }
  />
  …
</section>
```

```tsx
// Lists: DataTable (sorting, global filter, pagination, column visibility, loading, empty)
const columns: ColumnDef<Zone>[] = [
  { accessorKey: 'name', meta: { label: t('zones.name') },
    header: ({ column }) => <DataTableColumnHeader column={column} title={t('zones.name')} /> },
  { id: 'actions', enableHiding: false, cell: ({ row }) => <RowActions zone={row.original} /> },
];
<DataTable
  caption={t('zones.title')}
  columns={columns}
  data={query.data ?? []}
  loading={query.isPending}
  searchable
  toolbar={<Button size="sm">…</Button>}
  empty={<EmptyState icon={LayersIcon} title={t('zones.empty')} bordered={false} action={…} />}
/>
```

```tsx
// Forms: shadcn Form + react-hook-form + zod (messages = i18n keys, translated by FormMessage)
const form = useForm<Values>({ resolver: zodResolver(schema), defaultValues });
<Form {...form}>
  <form onSubmit={form.handleSubmit(onSubmit)} noValidate>
    <FormSection
      title={t('x.general')}
      description={t('x.generalHelp')}
      footer={
        <Button type="submit" disabled={mutation.isPending}>
          {t('common.actions.save')}
        </Button>
      }
    >
      <FieldRow control={form.control} name="name" label={t('x.name')}>
        {(field) => <Input {...field} />}
      </FieldRow>
      <FieldRow control={form.control} name="price_cents" label={t('x.price')}>
        {(field) => (
          <MoneyInput value={field.value} onChange={field.onChange} onBlur={field.onBlur} />
        )}
      </FieldRow>
      <FieldRow control={form.control} name="vat_bp" label={t('x.vat')}>
        {(field) => <PercentInput value={field.value} onChange={field.onChange} />}
      </FieldRow>
      <FieldRow control={form.control} name="starts_on" label={t('x.start')}>
        {(field) => <DatePicker value={field.value} onChange={field.onChange} />}
      </FieldRow>
      <FieldRow control={form.control} name="period" label={t('x.period')}>
        {(field) => <DateRangePicker value={field.value} onChange={field.onChange} />}
      </FieldRow>
      <FieldRow control={form.control} name="description" label={t('x.description')} optional>
        {(field) => (
          <I18nTextInput
            value={field.value}
            onChange={field.onChange}
            locales={establishment.enabled_locales}
            defaultLocale={establishment.default_locale}
            multiline
          />
        )}
      </FieldRow>
    </FormSection>
  </form>
</Form>;
```

| Pattern                                                          | Contract                                                                                                                                                        |
| ---------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `PageHeader`                                                     | `title` (the page `<h1 id="page-title">`), `description`, `actions`, `eyebrow`                                                                                  |
| `EmptyState`                                                     | `icon` (lucide), `title`, `description`, `action`, `children`, `bordered`                                                                                       |
| `ConfirmDialog`                                                  | `title`, `description`, `confirmLabel`, `destructive`, `onConfirm` (async: spinner, closes on success), `trigger` or `open`/`onOpenChange`                      |
| `DataTable`                                                      | see above; `onRowClick`, `getRowId`, `pageSize` (0 = no pagination), `initialSorting`                                                                           |
| `FormSection` / `FieldRow`                                       | settings layout; `FieldRow` = FormField+FormItem+FormLabel+FormControl+FormDescription+FormMessage                                                              |
| `MoneyInput`                                                     | `value: number \| null` **integer cents** ⇄ "1.234,50 €"; exact parsing (no floats); `null` when empty/invalid (+ `aria-invalid`, the typed text stays visible) |
| `PercentInput`                                                   | integer **basis points** ⇄ "5,5 %"                                                                                                                              |
| `DatePicker`                                                     | `value: "YYYY-MM-DD"`; dd/MM/yyyy; UI language, Monday first; `min`/`max` (year dropdown: ±10 years), `clearable`. Never `<input type="date">`                  |
| `DateRangePicker`                                                | `value: { from, to? }` ISO dates, two months                                                                                                                    |
| `I18nTextInput`                                                  | `value: Record<locale, string>`; tabs it/en/de/fr, default locale first, "da tradurre" marker                                                                   |
| `StatusBadge`                                                    | `tone: neutral \| info \| success \| warning \| danger \| highlight` or `spotStatus`; dot + text                                                                |
| `ThemeProvider` / `ThemeToggle` / `ThemeRadioItems` / `useTheme` | colour scheme                                                                                                                                                   |

Display formatting: `formatCents(cents)` → "1.234,50 €", `formatBasisPoints(bp)`,
`formatIsoDate('2026-07-14')` → "14/07/2026" (all Italian conventions, `Intl` it-IT).

## Rules for new screens

1. Look for a shadcn component or block first (https://ui.shadcn.com/docs/components), then
   an Arenile pattern; write a feature component only to _compose_ them.
2. No raw colours (`slate-*`, `red-*`, hex), no `var(--…)` in class names when a token class
   exists, no `style={{…}}` (only measured/SVG geometry in `shared/src/map` and the map editor).
   User data colours (rate periods, zones) go in SVG `fill` attributes.
3. Dates: `DatePicker`/`DateRangePicker` and `formatIsoDate`; money: `MoneyInput` and
   `formatCents`. Never US formats, never `<input type="date">`.
4. Tests: prefer role/label queries (Radix menus: `menuitem`, `menuitemradio`; Select:
   `combobox` + `option`; Dialog: `dialog`/`alertdialog`; Calendar days: `button` named
   "20 luglio 2026").
5. `npm run lint` runs `web/scripts/css-guard.mjs`: it has no exception lists, never add one.
